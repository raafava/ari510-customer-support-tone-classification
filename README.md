# Customer Support Tone Classification — Raafat Saeed

Competition: https://www.kaggle.com/competitions/customer-support-tone-classification

Predict the final customer message tone among five categories. Numeric labels 1-5 are learned directly from supplied training labels; no category-to-number mapping was invented. 302 training, 103 validation and 101 unlabeled test conversations. Metric: macro F1 (unweighted average over the five labels).

Train and validation data were kept separate. Text vectorizers were fitted only on training data; models and representations were selected using validation macro F1. Final predictions use the same train-only models. IDs are identifiers only. Test examples were not manually labeled. Source data is excluded from this package and must not be redistributed.

| Run | Input | Model | Validation macro F1 |
|---|---|---|---:|
| run1 | last_customer_message | word_logistic | 0.3335 |
| run2 | last_customer_message | char_logistic | 0.3328 |
| run3 | last_customer_message | word_neural | 0.2756 |
| run4 | context | word_logistic | 0.3509 |
| run5 | context | char_logistic | 0.3764 |
| run6 | context | word_neural | 0.2727 |

Selected run5: character TF-IDF (char_wb, 3-5 grams, 10000 max features, sublinear TF) and balanced logistic regression (C=2, max_iter=2000, seed=42). Input is conversation + FINAL CUSTOMER marker + final customer message repeated twice, emphasizing the target message while retaining context. No test-label information was used.

The run3 and run6 models are trained neural networks with 32 ReLU units, lbfgs optimizer, alpha=1, max_iter=1000, seed=42. They meet the trained-neural-network experiment requirement but underperformed the selected logistic model. Context helped the character model. Performance remains modest; most training examples belong to label 4 and minority-tone recognition is difficult. The 103-example validation set also makes model selection uncertain. Validation was used for model selection and is not an untouched final test set.

Host baseline and Kaggle scores are not yet verified. No candidate has been submitted by the assistant. Only actually uploaded runs should be listed as leaderboard submissions. The all-label-4 validation sanity baseline has macro F1 about 0.1197; this is not the host baseline.
